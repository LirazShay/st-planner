# Lifecycle E2E Smoke Test

Purpose: prove the S&T framework can carry a small goal through:

```
connect
→ plan
→ critique
→ release
→ execute
→ verify
→ learn
→ replan
→ execute again
→ verify root outcome
→ handoff
```

The test intentionally starts with a plausible assumption that runtime input contains no duplicates. Runtime evidence will falsify that assumption, forcing bounded replanning.

This is a framework test, not a recommendation for solving list-processing problems.
