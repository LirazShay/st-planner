# Examples

Examples are intentionally small. Their purpose is to demonstrate the planning protocol, not prescribe domain-specific architecture.

A useful example should show:

1. a concrete goal;
2. a root Strategy/Tactic pair;
3. a real decomposition based on necessity;
4. a sufficiency check;
5. executable leaves;
6. a STATUS file that a fresh session can resume from.

Do not copy example tactics into unrelated projects. Reuse the method, not the solution.
