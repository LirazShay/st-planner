# Examples

Examples are intentionally small. Their purpose is to demonstrate the ST Planner method, not prescribe domain-specific architecture.

A useful example should show:

1. a concrete outcome and relevant current reality;
2. a root Strategy/Tactic pair;
3. real decomposition based on necessity;
4. sufficiency checks;
5. material decisions only where they can change the plan;
6. implementation-ready leaves with objective success evidence;
7. a lightweight `EXECUTION.md` that assigns those leaves without duplicating their descriptions;
8. enough durable repository state for a fresh executor to continue without chat history.

Optional `STATUS.md` or `DECISIONS.md` should appear only when the example genuinely needs them.

Do not copy example tactics into unrelated projects. Reuse the method, not the solution.
